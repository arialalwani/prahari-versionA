Part 1 · Set the stage · recorder off

  1. Clear the screen

    Quit Slack, mail, Telegram. Close any window showing .env or an rtsp:// URL. Maximise the browser — below about 1280px the map and video wall stack instead of sitting side by side.

  2. Start the server

    cd C:\Users\Admin\PRAHARI\02_Code\prahari
.\run.ps1
    Must see

    A line ending Uvicorn running on http://127.0.0.1:8080. Leave this window open for the whole demo.

    If you see error while attempting to bind, something else holds 8080. Run Get-NetTCPConnection -LocalPort 8080 -State Listen and stop it — this has already happened once on this machine.

  3. Preflight — the go/no-go gate

    Second PowerShell window; the first is busy running the server.

    cd C:\Users\Admin\PRAHARI\02_Code\prahari
.\scripts\preflight_demo.ps1
    Must see

    Five PASS lines, then a final line that is exactly PASS. If the last line is FAIL, do not record.

  4. Sign in

    Go to http://127.0.0.1:8080 and press Ctrl+Shift+R once. The user is prefilled as judge; type the password you set.

    Must see

    Seven tabs, and a header strip reading ok · 11 cameras · 6 detections · WS connected.

  5. Open the one tile that plays

    Go to Cameras, find CAM-OWN-001 in the table, click Open. The clip appears in the Operations video wall. Leave it playing.

    Do this off camera. CAM-OWN-001 is not on the map, and hunting for it live costs fifteen seconds of your budget.

  6. Enrol the two photos optional

    Watchlist → Enroll Missing/Wanted Person. Gallery ID WL-004 and Camera ID CAM-OWN-001 are prefilled. Under Photo choose a.png from data\faces\WL-004, click Enroll, then repeat with b.png.

    Must see

    The box below the form reads Enrolled 1 image(s) into gallery WL-004.

    These are .png files in the app’s own data folder — not 03_Data, and not .jpg. Click Enroll exactly once per photo; every click appends another copy permanently and nothing on screen shows the running total. Skipping this step costs you nothing.
